Introducción · 5 min

¿Para qué sirven los efectos visuales?

CSS no solo cambia colores — transforma la experiencia completa

Sin efectos
h1 {
  color: blue;
}

div {
  background: white;
}
Con efectos CSS
h1 {
  text-shadow: 2px 2px 5px gray;
}

div {
  box-shadow: 5px 5px 15px gray;
  filter: blur(2px);
}
text-shadow · Persona 1 · 7 min

text-shadow

Agrega sombras al texto

/* sintaxis */
text-shadow: 2px 2px 5px gray;
2px Desplazamiento horizontal →
2px Desplazamiento vertical ↓
5px Desenfoque (blur)
gray Color de la sombra
/* ejemplo */
h1 {
  text-shadow: 3px 3px 4px black;
}

box-shadow · Persona 2 · 8 min

box-shadow

Sombras en cajas y elementos

Sombra externa

div {
  width: 200px;
  height: 100px;
  box-shadow: 5px 5px 15px gray;
}
Sombra afuera

Sombra interna (inset)

div {
  box-shadow:
    inset 0 0 10px black;
}
Sombra adentro
inset hace que la sombra vaya hacia adentro del elemento
Filtros CSS I · Persona 2 · 7 min

Filtros CSS

Modifican imágenes y elementos visualmente

blur()

Desenfoca el elemento

filter: blur(3px);

grayscale()

Convierte a blanco y negro

filter: grayscale(100%);

Vista previa

blur(3px) aplicado
grayscale(100%)
Filtros CSS II · Persona 3 · 8 min

Más filtros

Podés combinar varios filtros al mismo tiempo

brightness()

Más brillo (>100%) o más oscuro (<100%)

filter: brightness(150%);

contrast()

Aumenta o reduce el contraste

filter: contrast(200%);

sepia()

Efecto foto antigua / vintage

filter: sepia(100%);

Combinar filtros

filter: grayscale(100%) blur(2px);

Separados por un espacio — se aplican en orden de izquierda a derecha
